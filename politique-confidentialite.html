Protection des données personnelles

Politique de confidentialité ATKAN CAMP

Cette page explique quelles données personnelles peuvent être collectées par l’association, pourquoi elles sont utilisées, combien de temps elles sont conservées et quels sont les droits des personnes concernées.

L’association ATKAN CAMP accorde une grande importance à la protection des données personnelles des enfants, des familles, des bénévoles, des adhérents et des partenaires.

1. Responsable du traitement

Les données personnelles sont collectées par :

ATKAN CAMP
Association loi 1901 déclarée à Angers
Représentée par son président : Haithem RKIK
Adresse mail de contact : atkancamp@gmail.com

2. Données collectées

Pour les parents et responsables légaux

  • nom et prénom ;
  • adresse mail ;
  • numéro de téléphone ;
  • lien avec l’enfant ;
  • autorisation parentale ;
  • personne autorisée à récupérer l’enfant.

Pour les enfants inscrits

  • nom et prénom ;
  • date de naissance ;
  • âge ;
  • niveau scolaire ;
  • camp choisi ;
  • informations utiles à l’encadrement pédagogique ;
  • informations sanitaires nécessaires à la sécurité de l’enfant.

Pour les bénévoles

  • nom et prénom ;
  • adresse mail ;
  • numéro de téléphone ;
  • rôle dans l’association ;
  • disponibilités ;
  • documents nécessaires à l’encadrement des activités.

Pour les partenaires

  • nom de la structure ;
  • nom du contact ;
  • adresse mail ;
  • numéro de téléphone ;
  • objet de la collaboration.

3. Finalités de la collecte

Les données collectées sont utilisées uniquement pour :

  • gérer les inscriptions ;
  • organiser les activités de l’association ;
  • assurer le suivi des enfants ;
  • contacter les familles ;
  • gérer les présences et absences ;
  • assurer la sécurité des participants ;
  • organiser les réunions, événements et camps ;
  • gérer les bénévoles ;
  • communiquer avec les partenaires ;
  • respecter les obligations administratives et légales de l’association.
ATKAN CAMP ne collecte que les données nécessaires à son fonctionnement. Pas de collecte inutile, pas de fichier “fourre-tout”.

4. Base légale du traitement

Les données sont collectées sur la base :

  • du consentement des parents ou responsables légaux ;
  • de l’exécution de l’inscription aux activités ;
  • de l’intérêt légitime de l’association pour assurer son fonctionnement ;
  • des obligations légales applicables aux associations accueillant du public ou des mineurs.

5. Données de santé

Certaines informations de santé peuvent être demandées uniquement lorsqu’elles sont nécessaires à la sécurité de l’enfant :

  • allergies ;
  • traitement particulier ;
  • besoins spécifiques ;
  • personne à prévenir en cas d’urgence.

Ces données sont confidentielles et accessibles uniquement aux responsables autorisés de l’association.

6. Droit à l’image

Les photos et vidéos des enfants ne sont jamais utilisées sans autorisation écrite préalable des parents ou responsables légaux.

Une autorisation spécifique est demandée pour :

  • les photos ;
  • les vidéos ;
  • les publications sur les réseaux sociaux ;
  • le site internet ;
  • les supports de communication ;
  • les documents destinés aux partenaires.

Le refus du droit à l’image n’empêche pas l’enfant de participer aux activités.

7. Destinataires des données

Les données personnelles sont accessibles uniquement :

  • aux dirigeants autorisés de l’association ;
  • aux responsables pédagogiques concernés ;
  • aux bénévoles uniquement lorsque cela est nécessaire ;
  • aux organismes administratifs si la loi l’impose.

Les données ne sont pas vendues, louées ou transmises à des entreprises commerciales.

8. Durée de conservation

Les données sont conservées pendant une durée limitée :

  • dossiers d’inscription : durée de l’année d’activité + 2 ans maximum ;
  • fiches sanitaires : durée de l’activité + 1 an maximum ;
  • autorisations parentales : durée de l’activité + 2 ans maximum ;
  • données des bénévoles : durée de l’engagement + 2 ans maximum ;
  • données de contact partenaires : durée de la relation + 3 ans maximum ;
  • documents comptables : durée légale applicable.

À la fin de ces délais, les données sont supprimées ou archivées uniquement si une obligation légale l’impose.

9. Sécurité des données

ATKAN CAMP met en place des mesures simples pour protéger les données :

  • accès limité aux personnes autorisées ;
  • documents stockés dans un espace sécurisé ;
  • mots de passe solides ;
  • double authentification lorsque possible ;
  • suppression des accès lorsqu’un bénévole quitte l’association ;
  • non-partage des fichiers contenant des données personnelles ;
  • stockage papier dans un espace fermé si nécessaire.

10. Droits des personnes

Chaque personne concernée peut demander :

  • l’accès à ses données ;
  • la correction de ses données ;
  • la suppression de ses données ;
  • la limitation de leur utilisation ;
  • le retrait de son consentement ;
  • des informations sur l’utilisation de ses données.

Pour exercer ces droits, il suffit d’écrire à : atkancamp@gmail.com.

ATKAN CAMP répondra dans les meilleurs délais.

11. Réclamation

Si une personne estime que ses données ne sont pas correctement protégées, elle peut contacter ATKAN CAMP.

Elle peut également saisir la CNIL, autorité française chargée de la protection des données personnelles.

12. Engagement de l’association

ATKAN CAMP s’engage à utiliser les données personnelles avec sérieux, respect et transparence.

Les informations confiées à l’association servent uniquement à organiser les activités, protéger les enfants, accompagner les familles et assurer le bon fonctionnement du projet associatif.

Document public ou interne ?

Cette politique de protection des données personnelles doit être accessible aux personnes concernées. Elle peut donc être publiée sur le site internet, dans le pied de page, dans les formulaires d’inscription, dans les Google Forms, lors de l’adhésion à l’association ou transmise sur demande.

En revanche, les fichiers d’inscription, fiches sanitaires, listes d’enfants, autorisations parentales, registres internes, incidents ou signalements restent strictement confidentiels et accessibles uniquement aux personnes autorisées.
